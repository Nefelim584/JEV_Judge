# v0.1.0 — Stage A

First trained jev-lite model: `answerdotai/ModernBERT-large`, full fine-tuning on 25 public English datasets (run `stage_a-full-s42`).

**Model:** [Nefelim584/jev-lite-stage-a](https://huggingface.co/Nefelim584/jev-lite-stage-a) · **Report:** [STAGE_A.md](https://github.com/Nefelim584/JEV_Judge/blob/v0.1.0/STAGE_A.md)

### Results (cleaned test sets, accuracy: NLI / Laya / jev-lite)

| | trained sources | held-out templates | new sources |
|---|---|---|---|
| Bool | 0.763 / 0.723 / **0.882** | 0.569 / 0.770 / **0.902** | 0.542 / 0.519 / **0.603** |
| Choice | 0.595 / 0.596 / **0.803** | 0.617 / 0.622 / **0.794** | 0.558 / 0.585 / **0.635** |
| Score | 0.242 / 0.309 / **0.620** | 0.234 / 0.315 / **0.591** | — |

- Across 61 source × split cells: vs NLI 43 wins / 16 ties / 2 losses; vs Laya 52 / 9 / 0.
- Multi-hop HoVer 0.866 (NLI 0.707); answerability 0.907 (Laya 0.746); Score Spearman 0.67.
- Median latency 73 ms per request on an M1 Pro GPU.

### Known limitations

- Weak transfer to new domains: losses to NLI on ContractNLI Bool (−4.8) and FaithEval counterfactual (−6.1); too strict on unseen domains.
- Calibration breaks out of domain (Bool ECE 0.031 → 0.295); refusal detection does not transfer (FaithEval-unanswerable 0.49).
- TabFact partly solved by a shortcut; ClapNQ is a data artifact. 512-token context, one seed, no temperature scaling yet.
